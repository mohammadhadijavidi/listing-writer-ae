How listing-writer-ae works كيف يعمل كاتب الإعلانات

The model only writes prose from your facts. Code owns the compliance footer and decides what is publishable.
code

1. Property data

بيانات العقار
  • JSON / web form / API
  • type, beds, size, price
  • permit no., company, QR
  • off-plan: developer, project, escrow
  • agent notes (EN / AR)
→
code

2. Input checks

فحص المدخلات
  • permit, company, off-plan particulars, promo permit, QR (DLD / RERA)
  • claim rules on agent notes: risky sentences are kept out of the draft
→
LLM or mock

3. Writer

كتابة الإعلان بالعربية والإنجليزية
  • OpenAI-compatible, OpenRouter, Groq, Ollama, LM Studio, Anthropic
  • mock: deterministic bilingual template, no LLM
  • told: use only these facts, no guarantees, no superlatives
→
code

4. Footer + output checks

التذييل الإلزامي وفحص النص
  • permit no., company, ORN / BRN, off-plan details appended by code
  • claims (EN + AR), facts vs data (beds, size, price, status, amenities), style
LLM only: errors in step 4 go back to the writer as feedback, one revision round, then checked again.
